## Deviations from the plans

1. Backend: `vitest.config.ts` is now `vitest.config.mts` to remove an ESM warning.
2. Android: okhttp 5.1.0, kotlinx-serialization-json 1.9.0 and kotlinx-coroutines 1.10.2 replace the planned versions. The planned versions need Kotlin 2.4. See ADR-008.
3. Android: dark theme values for six tokens are derived because `DESIGN.md` has none.
4. iOS: `INFOPLIST_KEY_API_BASE_URL` did not reach the built plist. The build uses `ios/Config/Info-Debug.plist` and `Info-Release.plist`. See ADR-009.
5. iOS: color assets are `AppPrimary` and `AppSecondary` because the plain names clash with SwiftUI symbols.
6. iOS: summary counts expose their number as the accessibility value so UI tests find one element per count.
7. iOS: the test command uses `iPhone 17 Pro` and `-parallel-testing-enabled NO`.
